# Contact Form with SMTP Email

A complete, production-ready contact form with serverless email sending via SMTP. Deployed on Vercel for free.

## 🚀 Features

- Beautiful, responsive contact form Email SMTP
- Real-time form validation
- Serverless API endpoint for email sending
- SMTP support (Gmail, Outlook, SendGrid, etc.)
- Environment variable configuration
- One-click deployment to Vercel
