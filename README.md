# Contact Form Website

A production-ready contact form with serverless API, Nodemailer SMTP integration, and Vercel deployment.

## Features

- ✅ Modern, responsive glassmorphism design
- ✅ Client-side validation with real-time feedback
- ✅ Server-side validation with Nodemailer
- ✅ SMTP email delivery (Gmail, SendGrid, etc.)
- ✅ Environment variable configuration
- ✅ Vercel serverless function deployment
- ✅ Accessibility (WCAG compliant)
- ✅ Security (input sanitization, validation)
- ✅ Loading states and success/error messages

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js Serverless Function (Vercel)
- **Email**: Nodemailer + SMTP
- **Hosting**: Vercel
